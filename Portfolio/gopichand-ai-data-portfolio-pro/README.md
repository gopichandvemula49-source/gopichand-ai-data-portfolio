# Vemula Gopichand — AI Data Engineer Portfolio

A recruiter-focused cinematic portfolio built with React, TypeScript, Vite, Framer Motion and Lenis smooth scrolling.

## Why this design
- Uses the original graduation photo directly — no AI-generated face replacement.
- Front-loads measurable engineering impact instead of generic claims.
- Presents proprietary enterprise work as architecture/case-study summaries without exposing client code or data.
- Includes recruiter CTAs for email, LinkedIn and resume download.
- Responsive design for desktop and mobile.
- Smooth-scroll, reveal, parallax and cursor micro-interactions without excessive animation.

## Run locally
```bash
npm install
npm run dev
```

## Build for deployment
```bash
npm run build
```

Deploy the generated `dist/` folder to Vercel, Netlify, GitHub Pages or Cloudflare Pages.

## Customize
- Portrait: `public/assets/gopichand-graduation.jpg`
- Resume: `public/docs/Gopichand_Vemula_AI_Data_Engineer_Resume.pdf`
- Contact/LinkedIn: edit `src/components/Hero.tsx` and `Contact.tsx`
- Experience/case studies: edit `src/components/Work.tsx` and `Experience.tsx`

## Important
The project descriptions are written as representative professional engineering work. Add public GitHub links only for projects you are actually allowed to publish.
